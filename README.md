# 🌟 AURA & SOLE | Luxury Clothing & Footwear E-Commerce Store

An ultra-modern, high-converting e-commerce web platform for selling **Clothes and Shoes** featuring a vibrant **Royal Blue & Sunburst Yellow** color scheme, **Models wearing real outfits and footwear**, and up to **50% Flash Sale Discounts**.

---

## 🎨 Key Features & Highlights

1. **Vibrant Yellow & Blue Luxury Theme**:
   - Deep Royal Blue (`#0F172A`, `#1E3A8A`, `#2563EB`) and Sunburst Yellow (`#FACC15`, `#F59E0B`) color scheme.
   - Glassmorphism effects, glowing badges, smooth micro-interactions, and premium typography (*Outfit* & *Plus Jakarta Sans*).

2. **High-Fashion Models Wearing Outfits & Shoes**:
   - Curated high-resolution fashion model photography (male & female models posing in hoodies, tailored suits, trench coats, maxi dresses, varsity jackets, sneakers, oxfords, and running shoes).
   - "Model Worn Fit" tags with model height and size reference guidelines.

3. **Up to 50% Off Discount Promotions**:
   - Every product displays the original price, discounted price with savings amount, and up to `-50% OFF` badges.
   - Promo Code **`SAVE50`** and **`YELLOW50`** for an instant 50% checkout discount.
   - Live 24-hour Flash Sale countdown ticker.

4. **Curated Model Lookbook ("Shop the Look")**:
   - Complete matching ensembles (e.g., Streetwear Hoodie + Boost Running Shoes) that customers can buy as a bundle with 1-click 50% off.

5. **Interactive Shopping Experience**:
   - **Slide-out Cart Drawer** with free shipping progress bar ($150 target).
   - **Quick View Modal** with gallery thumbnails, size selector, and color swatches.
   - **Interactive Checkout Modal** with Cash on Delivery, Card, and EasyPaisa/JazzCash options.
   - **Wishlist System** to save favorite items.
   - **Currency Switcher**: `USD ($)`, `PKR (₨)`, `EUR (€)`, and `GBP (£)`.
   - **Web Audio Sound Effects**: Subtle auditory feedback for cart actions and celebration fanfares.
   - **Confetti Celebration**: Animated confetti on order confirmation.

---

## 🚀 How to Run the Website

Simply open `index.html` in any web browser:

- **Option 1**: Double-click `index.html` in your file explorer.
- **Option 2** (Windows PowerShell):
  ```powershell
  start index.html
  ```
- **Option 3** (VS Code Live Server or any static HTTP server):
  ```bash
  npx serve .
  ```
